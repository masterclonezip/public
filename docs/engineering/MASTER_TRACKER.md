## System Architecture & End-to-End Pipeline Map

```
[Admin Dashboard (Source of Truth)]
   │  (useAdminApps / useAdminSettings / AdminNewsTab / AdminVaultRoutes)
   ▼
[Firestore Primary Catalog (`store_data`: apps_chunk_*, settings, news, videos, faqs, developers)]
   │
   ├─► Live Server Sync (`POST /api/v1/admin/save-all` & `/api/v1/admin/sync-local` in `src/server/routes/adminVaultRoutes.ts:52–110`)
   │     ├─ Writes `src/lib/public_backup.json` (retains AES-encrypted links for backend resolution)
   │     ├─ Writes `src/lib/staticData.json` & `public-api/staticData.json` (links stripped)
   │     ├─ Writes `src/lib/staticData.ts`
   │     ├─ Generates `public/sitemap*.xml` & `public/sitemap*.xml.gz` via `generateAllSitemaps()` (`src/lib/sitemapGenerator.ts:372`)
   │     └─ Calls `clearSeoCache()` (`src/seoHelper.ts:57`)
   │
   ├─► GitHub Atomic Split-Sync (`useGitHubSync.ts:576–953` + `.github/workflows/split-sync.yml`)
   │     ├─ Compiles canonical apps (`compileCanonicalApp`), news (`compileCanonicalNews`), settings, and community review stats (`communityCatalogStats.json`)
   │     ├─ Seals AES Vault (`src/lib/secureVault.ts`)
   │     ├─ Generates `public/sitemap*.xml` and `public/robots.txt`
   │     └─ Commits all data + core engine files (`src/server/routes/githubSyncRoutes.ts:15–70`, mapping `src/AppPublic.tsx` -> `src/App.tsx`) atomically in 1 commit to `Dex` (Public Repo)
   │
   └─► Static Prerender & Build (`npm run build` → `vite build` → `scripts/prerender.ts` → `scripts/compress-dist.ts`)
         ├─ `scripts/prerender.ts` inlines compiled Vite CSS (`<style id="vite-inline-css">`) directly into `<head>` (0ms render-blocking CSS)
         ├─ Loads latest dataset (`public_backup.json` / `staticData.json` + `communityCatalogStats.json`)
         ├─ Invokes `injectSeoTags()` (`src/seoHelper.ts:242`) + `preRenderHtml()` (`src/seo/preRenderEngine.ts:23`)
         ├─ Emits static `.html` for every route (`/`, `/new-apps`, `/categories`, `/news`, `/videos`, `/developers`, `/app/:slug`, `/news/:slug`, `/category/:cat`, legal pages)
         ├─ Emits standardized `.xml` and level-9 compressed `.xml.gz` sitemaps in `dist/` and `public/`
         └─ `scripts/compress-dist.ts` pre-compresses `.gz` (level 9) and `.br` (level 11) assets
```
